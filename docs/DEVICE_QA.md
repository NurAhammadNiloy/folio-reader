## 1. Install and first load
1. Open the preview URL in Safari. The library loads with no errors. The offline badge changes to "Ready to use offline" within about 30 s.
2. Settings shows the Safari note that tabs and the Home Screen app keep separate libraries.
3. Share → Add to Home Screen. Launch it. The app opens standalone, the icon is correct, and safe areas are respected in portrait and landscape.

## 2. Import
1. Import `text-12p.pdf` and `geometry.pdf` from Files. Each import shows "Added to library".
2. Import `malformed.pdf`, `not-a-pdf.pdf` and an EPUB. Each shows a clear error, and no card is created.
3. Import `encrypted.pdf` (password `folio-test`). A wrong password says so. The right one imports.
4. Import a large real PDF of your own (do not share it). It imports, or shows the 100 MB limit message.
5. (iPad with keyboard and trackpad, or a desktop browser) Drag a PDF onto the library. It imports.

## 3. Reading
1. Page through in single, spread and continuous modes. Pages are sharp at 100% and 200%, with no blank tiles.
2. Pinch zoom in and out. It is smooth, with no jump to another page. Double-check the fit width and fit page buttons.
3. Rotate the device mid-book. The position is kept.
4. Swipe to turn pages in single mode. While in pen mode, swipes **draw** and do not turn pages.
5. Search for `zephyr7`. It jumps to page "5 · 7" and the match is highlighted.
6. Use the outline, thumbnails, page jump and bookmarks.

## 4. Apple Pencil and finger ink (the main release gate)
1. Pen mode: write a sentence with the Pencil. Strokes follow the tip with no visible lag, and pressure changes the width.
2. Rest your palm on the screen while writing. **The palm leaves no marks and does not scroll.**
3. Finger in pen mode with Settings → "In drawing mode, a finger" set to "Scrolls and zooms": the finger pans or zooms and never draws. Switch it with the finger toggle in the ink toolbar: now the finger draws.
4. Highlighter is translucent over text. The eraser removes whole strokes. Undo and redo work.
5. Zoom to 200%, rotate the view and change modes. The strokes stay on the same words.
6. Force-quit the app right after a stroke, then reopen. The completed stroke is there. Any in-progress stroke is offered for recovery.
7. Latency: with Safari Web Inspector attached, record a 10 s writing trace. Report the p95 time from input to paint. The target is ≤50 ms, but it is not a pass/fail claim without the trace.
8. Apple Pencil hover and double-tap do nothing harmful.

## 5. Offline
1. Turn on Airplane Mode. Relaunch the Home Screen app. The library, reading, ink and backup all work.
2. Unicode: open `unicode.pdf` offline. Bengali, Arabic and Japanese text render correctly.

## 6. Export and backup
1. Export an annotated PDF. Open it in Files/Preview (and Acrobat if available). The marks line up with the on-screen marks.
2. Export the notebook PDF and open it.
3. Make a full backup. Delete all data. Restore. All books, marks, notebooks, bookmarks and positions return.
4. Move a backup from Safari to the Home Screen app (they are separate libraries).

## 7. Accessibility
1. VoiceOver: navigate the library, open a book, use the toolbar, open and close dialogs. Every control has a name, and focus returns after dialogs.
2. Settings → Reduce motion (and the iOS setting). Page turns are not animated.
3. Larger text (Dynamic Type in Safari settings). Nothing overlaps.

## 8. Study split
1. Landscape iPad: book and notebook side by side. Drag the divider. Each side zooms independently.
2. Portrait: the split or tabs are usable. Link a notebook page to a book page and jump back.
